Vérification du BIOS ASRock A520M & Pilotes Chipset AMD

Les cartes mères AMD AM4 (A520/B550/X570) ont souffert d'un bug USB mondial connu provoquant la coupure du son et des grésillements sur les casques USB sans fil. Ce bug a été corrigé par le BIOS AGESA 1.2.0.7.

1

Vérifier votre version de BIOS actuelle

Ouvrez l'Invite de commande (cmd) ou PowerShell et collez cette commande :

wmic bios get smbiosbiosversion, releasedate

Si votre version est inférieure à P2.10 (ex: P1.20, P1.40, P1.80), votre carte mère contient le bug des ports USB AMD !

2

Télécharger le dernier BIOS ASRock A520M

Téléchargez la dernière version du BIOS (AGESA 1.2.0.7 ou supérieure) sur le site officiel d'ASRock :

🔗 Site Support officiel ASRock BIOS

La mise à jour du BIOS résout définitivement les coupures de courant des contrôleurs USB AMD Ryzen.

3

Installer les Pilotes AMD Chipset Software

Les pilotes du chipset AMD A520 gèrent la communication entre le processeur Ryzen et le bus USB.

🔗 Télécharger AMD Chipset Drivers (Socket AM4 / A520)
4

Mettre à jour Logitech G HUB

Assurez-vous que Logitech G HUB est mis à jour vers la version la plus récente pour que le firmware du dongle G733 soit flashé avec les correctifs de latence.

Générateur de Fréquence

1

Port USB Arrière ASRock A520M (USB 2.0 Noir)

Brancher le dongle G733 sur un port USB 2.0 Noir à l'arrière de la carte mère. Évitez les ports USB 3.0/3.2 (Bleu) qui génèrent des interférences 2.4 GHz perturbant la liaison sans fil LIGHTSPEED.

2

Désactiver la Suspension Sélective USB Windows

Appuyez sur Win + R, tapez :

powercfg.cpl

Modifiez le mode ➔ Modifier les paramètres d'alimentation avancés ➔ Paramètres USB ➔ Paramètre de suspension sélective USB ➔ Réglez sur Désactivé.

3

Désactiver le Surround DTS dans Logitech G HUB

Ouvrez Logitech G HUB ➔ Cliquez sur votre casque G733 ➔ Onglet Acoustique ➔ Décochez Activer le son surround.

Le surround virtuel de G HUB ré-échantillonne en 7.1 virtuel et sature le tampon du dongle USB G733.
4

Format Audio Windows (24 bits, 48000 Hz)

Appuyez sur Win + R, tapez mmsys.cpl. Dans les propriétés du Logitech G733, règlez sur 24 bits, 48000 Hz (Qualité Studio) et décochez le Mode Exclusif.
