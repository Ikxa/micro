Guide Pratique Windows (Panneau de Contrôle Son)

Appliquez les modifications recommandées étape par étape dans Windows 10 et Windows 11.

1

Ouvrir le Panneau de Contrôle Son Classique

Appuyez sur Win + R, tapez la commande ci-dessous et appuyez sur Entrée :

mmsys.cpl
2

Ajuster le Format par Défaut (Fréquence d'Échantillonnage)

Faites un clic droit sur votre casque/haut-parleurs principal -> Propriétés -> Onglet Statistiques avancées.

Sélectionnez : 24 bits, 48000 Hz (Qualité Studio) ou 16 bits, 48000 Hz (Qualité DVD).
3

Désactiver le Mode Exclusif & les Améliorations

Dans la même fenêtre :

  • Décochez "Autoriser les applications à prendre le contrôle exclusif de ce périphérique"
  • Allez dans l'onglet Améliorations (Enhancements) et cochez "Désactiver toutes les améliorations".
4

Désactiver l'Économie d'Énergie des Ports USB

Pour les casques USB / Cartes son DAC externes :

Appuyez sur Win + X -> Gestionnaire de périphériques -> Contrôleurs de bus USB -> Clic droit sur Concentrateur USB racine -> Propriétés -> Onglet Gestion de l'alimentation -> Décochez "Autoriser l'ordinateur à éteindre ce périphérique...".
